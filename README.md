# AI Chat

Чат с искусственным интеллектом на базе GigaChat. Простое одностраничное приложение - пишешь сообщение, получаешь ответ.

## Что понадобится

- Node.js 18 или новее
- npm (идёт вместе с Node.js)
- Ключ от GigaChat API - берётся бесплатно на [developers.sber.ru](https://developers.sber.ru/)

## Как запустить локально

### Сервер

Открой терминал, зайди в папку `server`:

```bash
cd server
cp .env.example .env
```

Открой файл `.env` и вставь свой ключ в строку `GIGACHAT_AUTH_KEY`.

Потом установи зависимости и запусти:

```bash
npm install
npm run dev
```

Сервер запустится на http://localhost:4000. Оставь этот терминал открытым.

### Фронтенд

Открой **новый** терминал , зайди в папку `frontend`:

```bash
cd frontend
npm install
npm run dev
```

Открывай в браузере http://localhost:3000 - всё готово.

## Скрипты

**Сервер:**

- `npm run dev` - разработка, перезагружается при изменениях
- `npm run build` - собрать проект в папку `dist/`
- `npm start` - запустить собранный проект
- `npm run pm2:start` - запуск в продакшене с автоперезапуском

**Фронтенд:**

- `npm run dev` - разработка
- `npm run build` - собрать для продакшена
- `npm run preview` - посмотреть собранную версию
- `npm run deploy` - выложить на GitHub Pages

## Переменные окружения

Сервер читает настройки из файла `.env`:

- `PORT` - на каком порту работать (по умолчанию 4000)
- `FRONTEND_URL` - откуда приходят запросы (для защиты от CORS)
- `GIGACHAT_AUTH_KEY` - ключ для API GigaChat, обязательно заполнить

## Если что-то пошло не так

**Ошибка 401 (Unauthorized)**

Проверь, что в `.env` правильный `GIGACHAT_AUTH_KEY`. Токен обновляется автоматически, но ключ должен быть рабочим.

**CORS ошибки в консоли браузера**

В `.env` у `FRONTEND_URL` должен быть точный адрес фронтенда. Для локальной разработки - `http://localhost:3000`.

**Сервер упал и не поднимается**

В режиме разработки перезапусти вручную: `npm run dev`.
